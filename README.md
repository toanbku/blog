# toanbku.com

A blog, technically. Built it five times. Wrote three posts.

Version five is a physics playground of every post I never finished: drag the drafts around, try to hit
Publish, and find the three posts that actually shipped.

- Next.js 16 (App Router)
- three.js via @react-three/fiber + drei
- Rapier physics via @react-three/rapier

```bash
npm install
npm run dev
```

Deploys to Vercel on push to `main`. The old posts live on
[Notion](https://toan-ho.notion.site/Toan-Ho-Blog-76e5a1b0ab35411487a6260d89ff4255).
